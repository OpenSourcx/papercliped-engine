# Vendored brand marks

Single-colour marks that simple-icons does not carry. `scripts/gen-brand-icons.mjs` reads these and writes them into
`src/data/brandIcons.ts` (with source and licence). Do not edit the SVGs; replace them from the source and regenerate.

| File | Mark | Source | Licence |
|---|---|---|---|
| `openai.svg` | OpenAI | paperclipai/paperclip `ui/public/brands/apps/openai.svg` @ cbf811c | MIT (Paperclip AI); artwork from Lobe Icons, MIT (LobeHub) |
| `xai.svg` | xAI / Grok | `ui/public/brands/apps/xai.svg` | same |
| `pi.svg` | Pi | `ui/public/brands/adapters/pi.svg` | same |
| `hermesagent.svg` | Hermes Agent | `ui/public/brands/adapters/hermesagent.svg` | same |

`PAPERCLIP-LICENSE` and `LOBE-LICENSE` are the licence texts. The marks are trademarks of their owners and identify the product they belong to.
Slack's colour artwork lives in `public/brands/slack.svg` (same source). Windows and OpenClaw have no openly licensed mark and show a labelled generic glyph.
