# Third-party material

- **Brand marks in the Store, Connectors and provider rows** are resolved in one place (`apps/console/src/data/brandMarks.ts`, drawn by `ui/BrandMark.tsx`) from `apps/console/src/data/brandIcons.ts`, which `scripts/gen-brand-icons.mjs` generates and which records a source and licence for every mark. Sources: [simple-icons](https://simpleicons.org) (CC0 1.0) for most marks; four single-colour marks simple-icons lacks (OpenAI, xAI/Grok, Pi, Hermes Agent) copied unmodified from `apps/console/brand-marks/`, which come from the Paperclip repository (`ui/public/brands`, MIT, Copyright (c) 2025 Paperclip AI, licence in `brand-marks/PAPERCLIP-LICENSE`) and, for the artwork, Lobe Icons (MIT, Copyright (c) 2023 LobeHub, licence in `brand-marks/LOBE-LICENSE`); and Slack's colour artwork `apps/console/public/brands/slack.svg`, taken from the same Paperclip repository. All marks are trademarks of their owners and appear only to identify the product they belong to; using them implies no endorsement. Where no openly licensed official mark exists (Windows, OpenClaw) or the entry is ours (Paperclip Runner, HTTP, Process, ePaperclip skills), the card shows a generic glyph whose accessible name says it is generic; an unknown or custom entry says "custom". There are no letter tiles. `test/brand-marks.test.ts` fails when a known provider falls back to a generic glyph. The console never loads a mark from another site.
- **Paperclip (the engine)** is the published npm package [`paperclipai`](https://github.com/paperclipai/paperclip), MIT licensed, installed unmodified at the exact version in `engine/package-lock.json` (no fork). Its licence text and copyright stay with the installed package and are reproduced in `NOTICE`. The Store's adapter names mirror its built-in adapter types. Its dependencies, including the agent SDKs and programs that are not open source (`@anthropic-ai/claude-agent-sdk`, `@cursor/sdk`, `@github/copilot`, the `opencode` programs), are fetched by the installer from the npm registry at install time and are **not** in our downloads; `NOTICE` and `THIRD_PARTY_LICENSES.md` (generated by `scripts/gen-notices.mjs`) list them and the terms to read before redistributing an image that bundles them. Upgrades and the supported version are in [UPGRADING.md](UPGRADING.md).
- **QR code generator** (`apps/console/src/vendor/qrcodegen.js`, with `qrcodegen.d.ts`) is the [QR Code generator library](https://www.nayuki.io/page/qr-code-generator-library) by Project Nayuki (MIT licence, copyright Project Nayuki), vendored as the upstream TypeScript file compiled to plain JavaScript without other changes (its licence notice stays at the top of the file). It draws the authenticator-app setup code in the browser as inline SVG, so no QR service is ever contacted.
