# Third-party material

- **Brand logos in the Store and Connectors** come from [simple-icons](https://simpleicons.org) (CC0 1.0), bundled by `scripts/gen-brand-icons.mjs` into `apps/console/src/data/brandIcons.ts`. They are trademarks of their owners and appear only to identify the product they belong to. Every known provider or plugin must use its reviewed provider mark on connector choices and management rows; a monogram is allowed only when a reviewed mark is unavailable. The console never loads a logo from another site.
- **Paperclip (the engine)** is the published npm package [`paperclipai`](https://github.com/paperclipai/paperclip), MIT licensed, installed unmodified at the exact version in `engine/package-lock.json` (no fork). Its licence text and copyright stay with the installed package and are reproduced in `NOTICE`. The Store's adapter names mirror its built-in adapter types. Its dependencies, including the agent SDKs and programs that are not open source (`@anthropic-ai/claude-agent-sdk`, `@cursor/sdk`, `@github/copilot`, the `opencode` programs), are fetched by the installer from the npm registry at install time and are **not** in our downloads; `NOTICE` and `THIRD_PARTY_LICENSES.md` (generated by `scripts/gen-notices.mjs`) list them and the terms to read before redistributing an image that bundles them. Upgrades and the supported version are in [UPGRADING.md](UPGRADING.md).
- **QR code generator** (`apps/console/src/vendor/qrcodegen.js`, with `qrcodegen.d.ts`) is the [QR Code generator library](https://www.nayuki.io/page/qr-code-generator-library) by Project Nayuki (MIT licence, copyright Project Nayuki), vendored as the upstream TypeScript file compiled to plain JavaScript without other changes (its licence notice stays at the top of the file). It draws the authenticator-app setup code in the browser as inline SVG, so no QR service is ever contacted.
