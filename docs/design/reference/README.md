# UI reference images

Screenshots the owner chose as references for ePaperclip's interface. They show the *feel and behaviour* to aim for; we keep our own tokens, themes and words (`apps/console/DESIGN.md`). Add new references here with a line below saying what to take from each.

| Image | What to take from it |
| --- | --- |
| `desktop-chat-overview.png` | The whole layout of a desktop AI-chat app: sidebar, centered conversation, the toolbar icons at the top right, cards and stacked tiles. This is the model for PinView. |
| `sidebar.png` | Sidebar rhythm: places (icon + label), then Pinned, a group per project, Recents; small group labels with a caret; plain rows; state icons at the end of rows; "Show more". |
| `sidebar-group-menu.png` | A group's menu on its heading: new item, new section, select, collapse all, expand all, with disabled items greyed. |
| `thread-grouped-tool-calls.png` | How an assistant's steps read in the thread: a collapsed "Ran 5 commands" line that opens into the individual steps, each folding again, with the command and its output inside. |
| `cards-plan-tiles.png` | The card column (Environment, Context with a percent bar, Connectors with Reconnect / Authenticate, Changes with Create PR) beside the Plan tile's task checklist and a file tile. |
| `cards-plan-file-viewer.png` | A file tile with a tab, a path line, the rendered file, a "continued from" pill and the tile's icon actions (search, outline, more, expand, close). |
| `tile-header-icons.png`, `tile-expand-close.png` | Tile header controls: bare icons, no boxes or borders around them, evenly spaced. Every icon control in the workspace should look like this. |
| `composer.png` | The composer: a roomy rounded field, a + on the left, send and voice on the right, and a line under it with the permission mode on the left and the model and effort on the right. |
| `composer-mention-picker.png` | What typing @ opens: a list of things to mention (folders, files, projects) with icons, the first one highlighted. |
| `windows-update.png`, `windows-update-more-options.png` | The Updates page's model: one status first, available updates with progress, then "More options" as rows with a toggle or a chevron. |
| `rail-hover-frames.png` | Frames from a chat app's server rail: tiles turn to rounded squares and take the accent on hover, a pill on the left grows, badges sit in the corner. |
| `epaperclip-rail-before.png` | Our rail before the accent and glass pass, for comparison. |

These images include the owner's own window contents (project and chat titles). Crop or blur anything private before adding more.
