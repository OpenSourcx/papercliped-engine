# Paperclip parity matrix: native paperclipai 2026.1023.0 vs ePaperclip

Generated by `node scripts/parity/build-matrix.mjs` from `scripts/parity/matrix-rows.mjs` and the saved runs in `docs/evidence/parity/*.json`. Do not edit by hand.

**Baseline.** `engine/package.json` pins `paperclipai` 2026.1023.0 exactly; the reference instance runs that package (health reports its commit 1b4c803). Newer upstream capabilities are not used as a baseline. Native API: Paperclip API, 989 operations, saved as `native-openapi.json`.

**Targets compared.** *native*: the stock engine on :3290 with its own UI. *epc*: the real ePaperclip host service (`services/epaperclip`, createApp) in front of a second real engine on :3291, signed in as a Proxmox person through `/engine/api`. Proxmox itself is the repo's fake (`fakePinPve`), so anything that needs a real hypervisor is not claimed.

**Evidence labels (never merged).** source-only, simulated, real Paperclip runtime, physical Proxmox+Orion hardware, real external provider or network. **Outcomes:** retained, operates differently, improved, incomplete, regression, blocked(prerequisite), not testable. A check cell reads `J14 E✓`: check id, N = native or E = epc, pass or fail. A failing cell on epc together with a passing one on native is the evidence for a closed route.

## Summary

- Rows: 58. By outcome: retained 24, operates differently 11, incomplete 9, regression 6, not testable 4, improved 3, blocked(prerequisite) 1.
- By evidence level: real Paperclip runtime 35, source-only 20, simulated 2, physical Proxmox+Orion hardware 1.
- Whole API: 989 operations, 187 reachable through the host proxy, 802 closed (`scripts/parity/coverage.mjs`). Native UI calls 645 distinct operations; 129 pass the proxy (`scripts/parity/ui-routes.mjs`, a lower bound). Capability probe: 97 GETs, same answer on 66, closed at the proxy on 28, differing on 3 (`probe.json`).
- Executable runs: journey 74 checks (native 37 pass; epc 34 pass, 3 fail = closed routes), access 22/22, seed 8/8, governance 14/14, extras 16 (epc cost-event write closed).
- **Cause of most gaps.** `services/epaperclip/src/engine-allow.ts` lets only the routes the console's client calls through `/engine/api`; the native engine UI is not served. Anything not in that list cannot exist in the console. This is a deliberate fail-closed design, so each gap is a product decision, not a bug, except where a native feature has no replacement.
